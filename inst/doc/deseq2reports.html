Introduction to deseq2reports

Overview

deseq2reports is a modular RNA-seq differential expression pipeline built on DESeq2. You can run everything in one call, or call each stage on its own and assemble the HTML report at the end.

Modules cover quality control, sample distance/PCA, differential expression, GSEA, optional WGCNA, CollecTRI/ULM TF activity, VIPER (bcellViper), STRING PPI connectivity, and a multi-page self-contained HTML report.

For a detailed, code-focused explanation of what each module does (inputs, outputs, and key arguments), see the companion vignette Module reference (vignette("deseq2reports-modules", package = "deseq2reports")).

Organism (human/mouse) is auto-detected from gene symbols via detect_organism() – there is no org argument. Row names should be standard HGNC/MGI symbols (not Ensembl/Entrez IDs).

One-command pipeline

library(deseq2reports)
library(DESeq2)

dds <- DESeqDataSetFromMatrix(
  countData = counts,
  colData = coldata,
  design = ~condition
)

out <- run_deseq2_pipeline(
  dds = dds,
  var = "condition",
  filter_method = "cpm",
  cpm_percentile = 0.05,
  shrinkage = "ashr",
  ranking = "pxfc",
  collections = c("HALLMARK", "GOBP", "REACTOME"),
  run_wgcna = TRUE,
  run_decoupler = TRUE,
  run_viper = TRUE,
  run_ppi = TRUE,
  render_html = TRUE,
  save_dir = "results"
)

Under results/ this writes per-module folders plus index.html:

Path Contents
qc/ Filtering summaries, library QC plots, qc.html
distance/ PCA / similarity artifacts (shown on the QC page)
deseq2/ Per-contrast DE tables & plots, deseq2.html (+ PPI when enabled)
clusterprofiler/ Per-contrast GSEA, clusterprofiler.html
wgcna/ Modules, ORA, wgcna.html (if run_wgcna = TRUE)
decoupler/ CollecTRI/ULM, decoupler.html (if run_decoupler = TRUE)
viper/ bcellViper/VIPER, viper.html (if run_viper = TRUE)
ppi/ STRING PPI CSVs/PDFs (embedded in DE/WGCNA pages when run_ppi = TRUE)
logs/ Timestamped run log + JSON session record

out is a list with dds, distance, diffexp, gsea, optional wgcna / decoupler / viper / ppi, and report_path (named HTML paths).

Modular usage

Each stage is a standalone function with the same arguments the pipeline uses. Typical workflow:

library(deseq2reports)
library(DESeq2)

dds <- DESeqDataSetFromMatrix(countData = counts, colData = coldata, design = ~condition)

# 1. QC / filtering
dds_qc <- run_qc(
  dds, var = "condition",
  filter_method = "cpm", cpm_percentile = 0.05,
  save_dir = "results/qc"
)

# 2. Sample similarity / PCA
distance_out <- run_distance_pca(
  dds_qc, var = "condition",
  save_dir = "results/distance"
)

# 3. Differential expression (all pairwise + one-vs-rest by default)
diffexp_out <- run_diffexp_pipeline(
  dds_qc, var = "condition",
  shrinkage = "ashr", ranking = "pxfc",
  save_dir = "results/deseq2"
)

# 4. GSEA
gsea_out <- run_gsea_pipeline(
  diffexp_out$results,
  collections = c("HALLMARK", "GOBP", "REACTOME"),
  ranking = "pxfc",
  save_dir = "results/clusterprofiler"
)

# 5. Optional modules
wgcna_out <- run_wgcna_pipeline(dds_qc, var = "condition", save_dir = "results/wgcna")
decoupler_out <- run_decoupler_pipeline(
  dds_qc, var = "condition", diffexp_out = diffexp_out,
  save_dir = "results/decoupler"
)
viper_out <- run_viper_pipeline(
  dds_qc, var = "condition", diffexp_out = diffexp_out,
  save_dir = "results/viper"
)
ppi_out <- run_ppi_pipeline(
  diffexp_out = diffexp_out, wgcna_out = wgcna_out,
  save_dir = "results/ppi"
)

# 6. HTML report
render_report(
  dds = dds_qc,
  var = "condition",
  distance_out = distance_out,
  diffexp_out = diffexp_out,
  gsea_out = gsea_out,
  wgcna_out = wgcna_out,
  decoupler_out = decoupler_out,
  viper_out = viper_out,
  ppi_out = ppi_out,
  save_dir = "results"
)

You can stop after any stage, inspect CSVs/PDFs, tweak arguments, and continue. Omit optional outputs (wgcna_out = NULL, etc.) and those report pages are greyed out in the navigation bar rather than removed.

Two-factor designs

Pass two grouping columns to build interaction contrasts automatically:

out <- run_deseq2_pipeline(
  dds,
  var = c("Tissue", "Isotype"),
  save_dir = "results_2factor"
)

Or set design = ~ Tissue * Isotype (and optional batch) yourself via design / resolve_design().

Reading the HTML report

Open results/index.html. Every section page is self-contained (self_contained = TRUE) with relative cross-links, so the folder tree can be copied offline. Each report section shows the minimal package call needed to reproduce that module’s results.
