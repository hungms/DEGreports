deseq2reports module reference

Purpose of this vignette

This HTML vignette explains what each deseq2reports module does, the functions used inside it, and their main / default settings. No figures – only code and narrative.

For a short “how do I run it?” guide, see vignette("deseq2reports", package = "deseq2reports"). For calculation / dependency flow diagrams, see vignette("deseq2reports-analysis-flow", package = "deseq2reports").

library(deseq2reports)
library(DESeq2)
# Assume `dds` is a DESeqDataSet with gene-symbol rownames and a grouping
# column such as `condition` in colData(dds).

Pipeline orchestration: run_deseq2_wald() / run_deseq2_lrt()

Role. Chains every stage below into one call and (by default) renders the multi-page HTML report. Prefer run_deseq2_wald() for group contrasts and run_deseq2_lrt() for time / ordered trajectories. run_deseq2_pipeline() is a deprecated alias of run_deseq2_wald().

out <- run_deseq2_wald(
  dds,
  var = "condition",          # required; length 2 → two-factor mode
  design = NULL,              # NULL → resolve_design(var, batch, include_interactions)
  include_interactions = FALSE, # TRUE → ~ A * B + interaction contrasts
  comparisons = NULL,         # NULL → full pairwise + one-vs-rest grid
  batch = NULL,
  batch_method = "limma",     # PCA viz only: "limma" | "combat" | "none"
  filter_method = "cpm",
  cpm_percentile = 0.05,
  shrinkage = "ashr",
  alpha = 0.05,
  lfc_threshold = 0.5,
  ranking = "log2FoldChange",
  collections = c("HALLMARK", "GOBP", "GOCC", "GOMF",
                  "KEGG_MEDICUS", "KEGG_LEGACY", "REACTOME", "PID"),
  n_scree_pcs = 10,
  n_loading_pcs = 6,
  n_top_genes = 10,
  top_label_n = 5,            # volcano labels per direction
  top_n_plot = 10,            # GSEA barplot pathways per NES direction
  run_wgcna = FALSE,
  wgcna_power = NULL,
  wgcna_min_module_size = 30,
  run_decoupler = FALSE,
  decoupler_n_tfs = 25,
  run_viper = FALSE,
  viper_n_tfs = 10,
  run_ppi = TRUE,
  ppi_top_n_hubs = 10,
  run_cspa = TRUE,
  cspa_n_markers = 25,
  render_html = TRUE,
  save_dir = getwd()
)

Wald stages (in order). run_qc() → run_distance_pca() → run_diffexp_pipeline() → run_cspa_marker_pipeline() → run_gsea_pipeline() (+ overlap) → optional WGCNA / decoupleR / VIPER / PPI → run_multihit_pipeline() → render_report().

LRT entry point.

out <- run_deseq2_lrt(
  dds,
  var = "genotype",             # or NULL for time-only
  time = "day",
  include_interactions = FALSE,
  run_wgcna = TRUE,
  run_decoupler = TRUE,
  run_viper = TRUE,
  run_ppi = TRUE,
  run_cspa = TRUE,
  cspa_n_markers = 10,          # top CSPA genes per degPatterns cluster
  degpatterns_minc = 15,
  save_dir = "results_lrt"
)

LRT stages: QC → distance → LRT grid (run_diffexp_lrt_pipeline()) → degPatterns → CSPA-by-cluster → cluster ORA → optional WGCNA → per-cluster TF (decoupleR / VIPER) → PPI → run_multihit_lrt_pipeline() → report. Ranked GSEA is not used in LRT mode.

Return value. List with dds, distance, diffexp, optional degpatterns / cluster_ora / gsea / wgcna / decoupler / viper / ppi / cspa / multihit, and report_path.

Helpers used by the orchestrator. resolve_design(), validate_comparisons() / expand_contrast_specs() / expand_lrt_specs(), detect_organism(), log_output().

Loading helpers: load_nfcore() / summarize_genes_dds()

Role. Build a gene-symbol-level DESeqDataSet from nf-core outputs or from an object whose rowData already carries symbols.

# nf-core/rnaseq .RData (object named `dds`) + 3-column tx2gene TSV
dds <- load_nfcore("salmon.merged.gene_counts.RData", "tx2gene.tsv")

# Or collapse an existing object by rowData symbol column
dds <- summarize_genes_dds(dds, gene_sym_col = "gene")

summarize_genes() sums count rows that share a gene symbol (used internally by both helpers).

Quality control: run_qc()

Role. Filter genes, estimate size factors, write QC summaries / plots, and attach metadata for the report.

dds_qc <- run_qc(
  dds,
  var = "condition",
  filter_method = "cpm",          # "cpm" | "count" | NULL
  cpm_percentile = 0.05,          # used when filter_method = "cpm"
  min_count = 10,                 # used when filter_method = "count"
  min_samples_per_group = NULL,   # NULL → size of smallest group
  remove_mt = FALSE,
  mt_pattern = "^MT-|^mt-",
  remove_xy = FALSE,
  gene_chr = NULL,                # needed if remove_xy = TRUE
  remove_vdj = NULL,              # NULL/FALSE | TRUE/"both" | "BCR" | "TCR"
  save_dir = getwd(),
  save_plot = TRUE
)

Supporting functions (defaults).

Function Defaults / role
plot_library_size(dds, var) Per-sample library sizes by group
plot_count_distribution(...) Pre/post filter density; cutoff line
detect_organism(genes, min_fraction = 0.5) "human" / "mouse" from symbols

Return value. Filtered DESeqDataSet; QC metadata in S4Vectors::metadata(dds_qc)$deseq2reports_qc.

  n_scree_pcs = 10,
  n_loading_pcs = 6,
  n_top_genes = 10,           # genes labelled per PC in loadings plot
  save_dir = getwd(),
  save_plot = TRUE
)

Supporting functions (defaults).

Function Defaults / role
plot_pca(pca_df, var, shape_var = NULL, pals = NULL) PC1 vs PC2 scatter
plot_pca_scree(..., n_scree_pcs = 10) % variance per PC
plot_pca_top_loadings(..., n_loading_pcs = 6, n_top_genes = 10) Top loading genes

Batch correction (when batch is set) is for plots only – not the DE model. Corrected and uncorrected PCA panels are both returned.

Differential expression: run_diffexp_pipeline() / run_diffexp()

Role. Fit DESeq2, run contrasts, shrink LFCs, rank genes, write tables and MA/volcano plots.

diffexp_out <- run_diffexp_pipeline(
  dds_qc,
  var = "condition",
  comparisons = NULL,         # NULL → generate_comparisons() / expand_contrast_specs()
  batch = NULL,               # added to design when set
  include_interactions = FALSE, # two-factor: interaction contrasts when TRUE
  shrinkage = "ashr",         # "ashr" | "apeglm" | "normal" | "none"
  alpha = 0.05,
  lfc_threshold = 0.5,
  ranking = "log2FoldChange",           # "pxfc" | "padj" | "log2FoldChange" | "stat"
  gene_col = "gene",
  top_label_n = 10,           # pipeline wrapper uses 5 when called via run_deseq2_wald()
  save_dir = getwd(),
  save_plot = TRUE
)

Supporting functions (defaults).

Function Defaults / role
run_diffexp(dds, contrast, shrinkage = "ashr", ...) Single-contrast fit
generate_comparisons(levels) All pairwise + one-vs-rest labels
expand_contrast_specs(dds, var, include_interactions = FALSE) Two-factor within-/optional interaction specs

Significance. sig requires padj < alpha and |log2FoldChange| > lfc_threshold.

Return value. results, by_comparison, contrast_specs.

Pathway enrichment (GSEA): run_gsea_pipeline()

Role. Rank genes per contrast; run fgsea for each MSigDB collection; write CSVs, NES barplots, and barcode panels.

gsea_out <- run_gsea_pipeline(
  diffexp_out$results,
  collections = "HALLMARK",   # pipeline default is broader (see above)
  ranking = "log2FoldChange",
  gene_col = "gene",
  min_size = 15,
  max_size = 500,
  top_n_plot = 10,            # pathways per NES direction in barplot/barcode
  save_dir = getwd(),
  save_plot = TRUE,
  run_clusterprofiler = FALSE
)

Barcode colouring. One track per pathway; red = NES > 0, blue = NES < 0 (not per-gene up/down).

GSEA leading-edge overlap: run_gsea_overlap_pipeline()

Role. Pool significant pathways (padj < alpha) across collections per contrast; Jaccard similarity of leading-edge gene sets; binary_cut clustering with a no-label heatmap and side word clouds (Suggests simplifyEnrichment). Shown at the bottom of the clusterProfiler HTML page.

gsea_overlap_out <- run_gsea_overlap_pipeline(
  gsea_out, alpha = 0.05,
  save_dir = "results/clusterprofiler"  # → <comp>/gsea_overlap/
)

Cross-analysis gene hits: run_multihit_pipeline() / run_multihit_lrt_pipeline()

Role (Wald). Per contrast, rank genes by hit count across DEG, GSEA leading edges (at most +1), VIPER, decoupleR, and CSPA; top-10 stacked barplots on the index page.

multihit_out <- run_multihit_pipeline(
  diffexp_out, gsea_out = gsea_out,
  viper_out = viper_out, decoupler_out = decoupler_out,
  cspa_out = cspa_out,
  top_n = 10, save_dir = "results/multihit"
)

Role (LRT). Per degPatterns cluster, top-10 table of genes co-occurring across LRT DEG membership, WGCNA modules, decoupleR TFs, and VIPER TFs (run_multihit_lrt_pipeline()).

WGCNA: run_wgcna_pipeline()

Role. Soft-threshold selection, signed modules, module–trait correlation, hub genes (kME), per-module ORA.

wgcna_out <- run_wgcna_pipeline(
  dds_qc,
  var = "condition",
  power = NULL,                             # NULL → auto-select
  power_vector = c(1:10, seq(12, 20, 2)),
  rsq_cutoff = 0.85,
  network_type = "signed",
  min_module_size = 30,
  merge_cut_height = 0.25,
  max_modules = 15L,                        # merge toward ≤ this many modules
  cor_type = "pearson",
  top_n_hub_genes = 10,
  ora_collection = c("GOBP", "GOCC", "GOMF",
                     "KEGG_MEDICUS", "KEGG_LEGACY", "REACTOME", "PID"),
  top_n_ora = 10,
  gene_col = "gene",
  save_dir = getwd(),
  save_plot = TRUE
)

Supporting functions (defaults).

Function Defaults / role
plot_soft_threshold(fit_indices) Scale-free topology / mean connectivity
plot_module_sizes(module_df) Genes per module
plot_module_trait_heatmap(module_trait_cor) Module vs trait correlation
plot_module_eigengene_heatmap(MEs) Sample × ME heatmap
plot_module_ora_dotplot(ora_df, top_n = 10) Per-module ORA dots

Modules are renamed "Module 1", "Module 2", … by size; WGCNA grey → "Unassigned" (excluded from ORA). HTML module-gene tables list all members by |kME| (top 10 rows shown by default).

Requires. Suggests WGCNA, withr.

  minsize = 5,                # min targets per TF for run_ulm
  gene_col = "gene",
  save_dir = getwd(),
  save_plot = TRUE
)

Supporting functions (defaults).

Function Defaults / role
plot_tf_sample_heatmap(sample_acts, n_tfs = 50) Sample × TF heatmap
plot_tf_contrast_barplot(acts, n_tfs = 25, title = NULL) Contrast TF barplot

Sample scores use blind VST; contrast scores use DESeq2 Wald stat (or LRT cluster stat when diffexp_out comes from lrt_clusters_diffexp_for_tf()). Prefer a local CollecTRI CSV under example_data/collectri_{human,mouse}.csv or pass collectri_file=.

STRING PPI connectivity: run_ppi_pipeline()

Role. STRING subgraphs for DE contrasts and (optionally) WGCNA modules; BioNERO-style communities / hubs.

ppi_out <- run_ppi_pipeline(
  diffexp_out = diffexp_out,
  wgcna_out = NULL,             # or wgcna_out for module networks
  org = NULL,                   # NULL → detect_organism()
  top_n_hubs = 10L,
  max_genes = Inf,              # all sig DEGs / module members as seeds
  max_plot_nodes = 100L,        # degree cap for the plotted network
  score_threshold = 400L,       # STRING combined score (0–1000)
  gene_col = "gene",
  alpha = 0.05,                 # DE direction annotation only
  lfc_threshold = 0.5,
  save_dir = getwd(),
  save_plot = TRUE
)

Supporting functions (defaults).

Function Defaults / role
plot_ppi_connectivity(nodes, edges, top_n_hubs = 10L) Static network
make_interactive_ppi(nodes, edges = NULL, top_n_hubs = 10L) Hoverable plotly

Funnel. seeds → STRING-mapped → genes with ≥1 edge → plot may keep top max_plot_nodes by degree. Degree tables keep all genes with edges (HTML shows top 10 by default).

Requires. Suggests STRINGdb, igraph. Embedded in DE / WGCNA pages (no separate nav page).

Minimal modular script

library(deseq2reports)
library(DESeq2)

dds <- DESeqDataSetFromMatrix(countData = counts, colData = coldata, design = ~condition)
dds_qc <- run_qc(dds, var = "condition")                 # filter_method = "cpm"
distance_out <- run_distance_pca(dds_qc, var = "condition")
diffexp_out <- run_diffexp_pipeline(dds_qc, var = "condition")
gsea_out <- run_gsea_pipeline(diffexp_out$results)       # collections = "HALLMARK"

# Optional:
# wgcna_out <- run_wgcna_pipeline(dds_qc, var = "condition")
# decoupler_out <- run_decoupler_pipeline(dds_qc, var = "condition", diffexp_out = diffexp_out)
# viper_out <- run_viper_pipeline(dds_qc, var = "condition", diffexp_out = diffexp_out)
# ppi_out <- run_ppi_pipeline(diffexp_out = diffexp_out)

render_report(
  dds_qc, var = "condition",
  distance_out = distance_out,
  diffexp_out = diffexp_out,
  gsea_out = gsea_out,
  save_dir = "results"
)
