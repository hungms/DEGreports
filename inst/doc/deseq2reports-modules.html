deseq2reports module reference

Purpose of this vignette

This HTML vignette explains what each deseq2reports module does, the functions used inside it, and their main / default settings. No figures – only code and narrative.

For a short “how do I run it?” guide, see vignette("deseq2reports", package = "deseq2reports"). For calculation / dependency flow diagrams, see vignette("deseq2reports-analysis-flow", package = "deseq2reports").

library(deseq2reports)
library(DESeq2)
# Assume `dds` is a DESeqDataSet with gene-symbol rownames and a grouping
# column such as `condition` in colData(dds).

Pipeline orchestration: run_deseq2_wald() / run_deseq2_lrt() / run_deseq2_deg()

Role. Chains every stage below into one call and (by default) renders the multi-page HTML report. Prefer run_deseq2_wald() for group contrasts, run_deseq2_lrt() for time / ordered trajectories, and run_deseq2_deg() when starting from a merged DEG table (no DESeqDataSet). run_deseq2_pipeline() is a deprecated alias of run_deseq2_wald().

out <- run_deseq2_wald(
  dds,
  var = "condition",          # length 1–3
  design = NULL,              # NULL → resolve_design(var, batch, include_interactions)
  include_interactions = FALSE, # TRUE → adds difference-of-differences contrasts
  comparisons = NULL,         # NULL → full pairwise + one-vs-rest grid
  batch = NULL,
  platform = "rnaseq",        # batch correction: "rnaseq" → ComBat-seq,
                              #                   "microarray" → ComBat
  filter_method = "cpm",
  cpm_percentile = 0.05,
  ranking = "log2FoldChange",
  collections = c("HALLMARK", "GOBP", "GOCC", "GOMF",
                  "KEGG", "REACTOME", "PID"),
  n_scree_pcs = 10,
  n_loading_pcs = 6,
  n_top_genes = 10,
  top_label_n = 5,            # volcano labels per direction
  top_n_plot = 10,            # GSEA barplot pathways per NES direction
  # Optional modules (default FALSE):
  run_gsva = FALSE,
  run_wgcna = FALSE,
  run_decoupler_tf = FALSE,
  run_decoupler_ccc = FALSE,
  run_viper = FALSE,
  # Default-on:
  run_cspa = TRUE,
  render_html = TRUE,
  parallel_render = FALSE,    # knit contrast pages in parallel (future.apply)
  render_workers = NULL,      # NULL → min(4, detectCores() - 1)
  use_targets = FALSE,        # TRUE → render_report_targets() (resumable)
  save_dir = getwd()
)

Statistical and plotting thresholds – LFC shrinkage, alpha, the LFC cutoff, GSVA heatmap size, WGCNA minimum module size, and the hub / TF / marker counts – are fixed by the pipeline so runs stay comparable. Call the module functions below directly to change them.

Wald stages (in order). run_qc() → run_distance_pca() → run_diffexp_pipeline() → run_cspa_marker_pipeline() → run_gsea_pipeline() (+ overlap) → optional GSVA / WGCNA / decoupler-tf / decoupler-ccc / VIPER → run_multihit_pipeline() → render_report(). PPI and CSPA run by default.

LRT entry point.

out <- run_deseq2_lrt(
  dds,
  var = "genotype",             # or NULL for time-only
  time = "day",
  include_interactions = FALSE,
  run_gsva = TRUE,
  run_wgcna = TRUE,
  run_decoupler_tf = TRUE,
  run_decoupler_ccc = TRUE,
  run_viper = TRUE,
  degpatterns_minc = 15,
  save_dir = "results_lrt"
)

LRT stages: QC → distance → LRT grid (run_diffexp_lrt_pipeline()) → degPatterns → CSPA-by-cluster → cluster ORA → optional WGCNA → per-cluster TF (decoupler-tf / VIPER) and optional decoupler-ccc (scored per test and per cluster) → PPI → run_multihit_lrt_pipeline() → report. Ranked GSEA is not used in LRT mode.

Return value. List with dds, distance, diffexp, gsea / PPI / CSPA (default-on), optional gsva / wgcna / decoupler_tf / decoupler_ccc / viper, plus multihit and report_path. LRT also returns degpatterns / cluster_ora.

Helpers used by the orchestrator. resolve_design(), validate_comparisons() / expand_contrast_specs() / expand_lrt_specs(), detect_organism(), log_output().

Loading helpers: load_nfcore() / summarize_genes_dds()

Role. Build a gene-symbol-level DESeqDataSet from nf-core outputs or from an object whose rowData already carries symbols.

# nf-core/rnaseq .RData (object named `dds`) + 3-column tx2gene TSV
dds <- load_nfcore("salmon.merged.gene_counts.RData", "tx2gene.tsv")

# Or collapse an existing object by rowData symbol column
dds <- summarize_genes_dds(dds, gene_sym_col = "gene")

summarize_genes() sums count rows that share a gene symbol (used internally by both helpers).

Quality control: run_qc()

Role. Filter genes, estimate size factors, write QC summaries / plots, and attach metadata for the report. The HTML Sample QC section (before Library QC) reports per-sample detected genes and total transcripts from the input count matrix (qc_sample_summary.csv).

dds_qc <- run_qc(
  dds,
  var = "condition",
  filter_method = "cpm",          # "cpm" | "count" | NULL
  cpm_percentile = 0.05,          # used when filter_method = "cpm"
  min_count = 10,                 # used when filter_method = "count"
  min_samples_per_group = NULL,   # NULL → size of smallest group
  remove_mt = FALSE,
  mt_pattern = "^MT-|^mt-",
  remove_xy = FALSE,
  gene_chr = NULL,                # needed if remove_xy = TRUE
  remove_vdj = NULL,              # NULL/FALSE | TRUE/"both" | "BCR" | "TCR"
  save_dir = getwd(),
  save_plot = TRUE
)

Differential expression: run_diffexp_pipeline() / run_diffexp()

Role. Fit DESeq2, run contrasts, shrink LFCs, rank genes, write tables and MA/volcano plots.

diffexp_out <- run_diffexp_pipeline(
  dds_qc,
  var = "condition",
  comparisons = NULL,         # NULL → generate_comparisons() / expand_contrast_specs()
  batch = NULL,               # added to design when set
  include_interactions = FALSE, # two-/three-factor: interaction contrasts when TRUE
  shrinkage = "ashr",         # "ashr" | "apeglm" | "normal" | "none"
  alpha = 0.05,
  lfc_threshold = 0.5,
  ranking = "log2FoldChange",           # "pxfc" | "padj" | "log2FoldChange" | "stat"
  gene_col = "gene",
  top_label_n = 10,           # pipeline wrapper uses 5 when called via run_deseq2_wald()
  save_dir = getwd(),
  save_plot = TRUE
)

Sample-level pathway scores (GSVA): run_gsva_pipeline()

Role. Score every gene set in each sample rather than testing a ranked contrast, so pathways can be compared sample by sample on the GSVA HTML page. Independent of the GSEA module above.

gsva_out <- run_gsva_pipeline(
  dds_qc,
  var = "condition",
  collections = c("HALLMARK", "GOBP", "GOCC", "GOMF",
                  "KEGG", "REACTOME", "PID"),
  n_heatmap = 50,             # heatmap rows for non-HALLMARK collections
  min_size = 10,              # min overlapping genes per set
  gene_sets = NULL,           # supply to bypass msigdbr (tests)
  batch = NULL,
  platform = "rnaseq",        # ComBat-seq (or ComBat) when batch is set
  save_dir = "results/gsva",
  save_plot = TRUE
)

Supporting functions (defaults).

Function Defaults / role
plot_gsva_heatmap(scores, group, var_label = "group", keep = NULL, collection = NULL) Row-scaled sample × pathway heatmap

Scores come from blind VST (batch-corrected first when batch is set). Every collection is scored in full to CSV; HALLMARK is heatmapped in full, while the large collections are heatmapped as the top n_heatmap pathways by Kruskal–Wallis association with var – a GSEA-style padj cutoff does not apply here, since every set gets a score.

Return value. org, collections, scores (pathway × sample matrices), stats (ranking tables), heatmaps, n_heatmap, min_size, var.

Requires. Import GSVA.

Cross-analysis gene hits: run_multihit_pipeline() / run_multihit_lrt_pipeline()

Role (Wald). Per contrast, rank genes by hit count across DEG, GSEA leading edges (at most +1), VIPER, decoupleR, and CSPA; top-10 stacked barplots on the dedicated Multihit HTML page (multihit/multihit.html, after VIPER in the nav).

multihit_out <- run_multihit_pipeline(
  diffexp_out, gsea_out = gsea_out,
  viper_out = viper_out, decoupler_tf_out = decoupler_tf_out,
  cspa_out = cspa_out,
  top_n = 10, save_dir = "results/multihit"
)

Role (LRT). Per degPatterns cluster, top-10 table of genes co-occurring across LRT DEG membership, WGCNA modules, decoupleR TFs, and VIPER TFs (run_multihit_lrt_pipeline()), also on the Multihit page.

Ligand–receptor activity (cell–cell communication): run_decoupler_ccc_pipeline()

Role. Score LIANA-style ligand–receptor pairs as a decoupleR network (source = the pair, target = its ligand or receptor gene, mor = 1) with ULM on each contrast’s stat vector, on the decoupleR-CCC page. Separate module from CollecTRI TF activity above.

decoupler_ccc_out <- run_decoupler_ccc_pipeline(
  diffexp_out = diffexp_out,
  cluster_diffexp = NULL,     # or lrt_clusters_diffexp_for_tf() output (LRT)
  n_lr = 10,                  # top pairs per direction in the barplot
  minsize = 2,                # a ligand and a receptor
  gene_col = "gene",
  lr_file = NULL,             # local CSV (source, target, mor)
  lr_net = NULL,              # pre-built network; skips any fetch (tests)
  save_dir = "results/decoupler-ccc",
  save_plot = TRUE
)

Supporting functions (defaults).

Function Defaults / role
plot_lr_contrast_barplot(contrast_acts, n_lr = 10, title = NULL) Top 10 up / 10 down pairs per comparison

The L–R resource is resolved in order: local lr_file CSV, then liana’s Consensus resource if that package is installed, then OmniPath ligand–receptor-extra interactions. Whatever is used is written out as liana_lr_network.csv.

LRT clusters. Passing cluster_diffexp (the same lrt_clusters_diffexp_for_tf() object decoupler-tf and VIPER consume) runs one extra ULM per degPatterns cluster into <lrt>/cluster_<n>/. Because a cluster signature holds only that cluster’s genes, minsize = 2 means a pair surfaces for a cluster only when both partners are members of it – which is the attribution the whole-test fit cannot make, and also why a cluster may legitimately score no pair at all. run_deseq2_lrt() passes it automatically, and the report then shows one tab per cluster with the pooled whole-test table kept below.

Return value. org, net, contrast_acts, contrast_barplots, n_lr, minsize, plus cluster_acts / cluster_barplots / clusters_by_test when cluster_diffexp was supplied.

Requires. Import decoupleR; liana (Suggests) or OmnipathR for the network unless lr_file / lr_net is given.

HTML report: render_report()

Role. Knit bundled Rmds into a multi-page, folder-bundled report tree.

render_report(
  dds = dds_qc,
  var = "condition",
  distance_out = distance_out,
  diffexp_out = diffexp_out,
  gsea_out = gsea_out,
  gsea_overlap_out = NULL,
  multihit_out = NULL,
  wgcna_out = NULL,
  decoupler_tf_out = NULL,
  ppi_out = NULL,
  viper_out = NULL,
  cspa_out = NULL,
  gsva_out = NULL,
  decoupler_ccc_out = NULL,
  degpatterns_out = NULL,       # LRT: clusters and their plots
  cluster_ora_out = NULL,       # LRT: per-cluster ORA
  alpha = 0.05,
  lfc_threshold = 0.5,
  run_args = NULL,              # optional list shown on the index page
  save_dir = getwd(),
  parallel_render = FALSE,      # knit contrast pages across render_workers
  render_workers = NULL,        # NULL → min(4, detectCores() - 1)
  contrasts_only = FALSE        # skip hub pages (used by render_report_targets)
)

Pages. index.html, qc/qc.html, deseq2/deseq2.html (+ per-contrast pages), clusterprofiler/clusterprofiler.html (+ per-contrast), optional wgcna/, decoupler-tf/, decoupler-ccc/, viper/, multihit/. Missing optional modules are greyed out in the nav. Pass dds = NULL to skip / grey out QC (DEG-table pipeline).

Speed and resumability. With parallel_render = TRUE the per-contrast pages are knitted concurrently through future.apply; each worker gets its own intermediates_dir, and a page whose pandoc step dies in a worker is retried once alone in the main session before it is given up as a gap in the report. render_report_targets() is a drop-in alternative that makes each hub page a targets target, so re-rendering skips the pages whose inputs have not changed and contrast pages follow via contrasts_only = TRUE; the entry points reach it through use_targets = TRUE.

Portability. Pages are folder-bundled (self_contained = FALSE): assets go to a lib/ beside each page, figures to <page>_figures/, and every nav link, figure and CSV/PDF download is a relative path. The results tree can therefore be moved, copied or archived and still opened offline, as long as it moves as a whole.

Hub summaries. DESeq2 and clusterProfiler hubs include summarize_deg_contrasts() / summarize_gsea_contrasts() tables (n and % significant up/down). Multi-factor contrasts are grouped by emit_contrast_nav() under “Main effects” and “Interactions (difference of differences)” headings, and the DESeq2 hub adds an interaction_question_table() stating each interaction as a question with the meaning of a positive log2FoldChange.
