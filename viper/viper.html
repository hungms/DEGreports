VIPER protein activity (bcellViper)

Master-regulator / protein activity inferred with VIPER (viper / msviper) using the human B-cell transcriptional regulon from the bcellViper data package (Alvarez et al., Nat Genet 2016). Detected organism: mouse (mouse genes mapped to human orthologs via babelgene before scoring). Regulons loaded: 621.

Sample-level scores use gene-wise z-scored ComBat-seq then VST expression with viper(). Contrast-level master-regulator analysis uses each comparison’s DESeq2 Wald stat as the gene-expression signature with msviper(), and the classic VIPER barcode plot (plot.msviper) shows positively/negatively regulated targets in red/blue along the ranked signature.

Reproduce VIPER with this package module:

viper_out <- run_viper_pipeline(
  dds_qc, var = "condition", diffexp_out = diffexp_out
)
