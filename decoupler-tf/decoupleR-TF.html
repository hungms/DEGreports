decoupleR-TF

Transcription-factor (TF) activities inferred with decoupleR using the CollecTRI prior-knowledge network and the Univariate Linear Model (ULM) method, following the bulk RNA-seq TF activity vignette. Organism for CollecTRI: mouse.

Sample-level scores use ComBat-seq then VST expression; contrast-level scores use each comparison’s DESeq2 Wald stat as the gene-level statistic.

Reproduce decoupleR-TF analysis with this package module:

decoupler_tf_out <- run_decoupler_tf_pipeline(
  dds_qc, var = "condition", diffexp_out = diffexp_out
)
