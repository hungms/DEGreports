decoupleR ligand–receptor (CCC)

Ligand–receptor (cell–cell communication) enrichment inferred with decoupleR using a LIANA / OmniPath ligand–receptor resource and ULM, following the bulk functional analysis tutorial. Each interaction is a small gene set (ligand + receptor, complexes exploded); co-regulation of the pair is scored from DESeq2 Wald stat values. Organism: mouse.

This page is independent of CollecTRI TF activity (decoupleR-TF).

Reproduce ligand–receptor ULM with this package module:

ccc_out <- run_decoupler_ccc_pipeline(diffexp_out)
