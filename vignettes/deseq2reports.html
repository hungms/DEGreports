Introduction to deseq2reports

Overview

deseq2reports is a modular RNA-seq differential expression pipeline built on DESeq2. You can run everything in one call, or call each stage on its own and assemble the HTML report at the end.

Two one-command entry points:

Function When to use
run_deseq2_wald() Standard group contrasts (pairwise / one-vs-rest / two-factor)
run_deseq2_lrt() Time-course / ordered trajectory (LRT + degPatterns clusters)

(run_deseq2_pipeline() remains as a deprecated alias of run_deseq2_wald().)

Modules cover quality control, sample distance/PCA, differential expression, GSEA (Wald) or cluster ORA (LRT), optional WGCNA, CollecTRI/ULM TF activity, VIPER (bcellViper), STRING PPI, CSPA surface markers, cross-analysis gene hits, and a multi-page HTML report.

Companion vignettes:

  • Module reference — vignette("deseq2reports-modules", package = "deseq2reports")
  • Analysis flow — vignette("deseq2reports-analysis-flow", package = "deseq2reports")

Organism (human/mouse) is auto-detected from gene symbols via detect_organism() – there is no org argument. Row names should be standard HGNC/MGI symbols (not Ensembl/Entrez IDs). Use summarize_genes_dds() / load_nfcore() when you start from transcript- or Ensembl-level counts.

Loading a DESeqDataSet

From a count matrix:

library(deseq2reports)
library(DESeq2)

dds <- DESeqDataSetFromMatrix(
  countData = counts,
  colData = coldata,
  design = ~ condition
)

From an nf-core/rnaseq .RData + tx2gene TSV (collapses features that share a gene symbol):

dds <- load_nfcore(
  rdata = "salmon.merged.gene_counts.RData",
  tx2gene = "tx2gene.tsv"
)

Or attach symbols yourself and collapse:

rowData(dds)$gene <- gene_symbols
dds <- summarize_genes_dds(dds, gene_sym_col = "gene")

One-command Wald pipeline

out <- run_deseq2_wald(
  dds = dds,
  var = "condition",
  filter_method = "cpm",
  cpm_percentile = 0.05,
  shrinkage = "ashr",
  ranking = "log2FoldChange",
  collections = c("HALLMARK", "GOBP", "REACTOME"),
  run_wgcna = TRUE,
  run_decoupler = TRUE,
  run_viper = TRUE,
  run_ppi = TRUE,
  run_cspa = TRUE,
  render_html = TRUE,
  save_dir = "results"
)

Under results/ this writes per-module folders plus index.html:

Path Contents
qc/ Filtering summaries, library QC plots, qc.html
distance/ PCA / similarity artifacts (shown on the QC page)
deseq2/ (+ deseq2/cspa/) Per-contrast DE tables & plots, CSPA, deseq2.html
clusterprofiler/ Per-contrast GSEA (+ overlap), clusterprofiler.html
wgcna/ Modules, ORA, wgcna.html (if run_wgcna = TRUE)
decoupler/ CollecTRI/ULM, decoupler.html (if run_decoupler = TRUE)
viper/ bcellViper/VIPER, viper.html (if run_viper = TRUE)
ppi/ STRING PPI CSVs/PDFs (embedded in DE/WGCNA pages)
multihit/ Cross-analysis top genes (shown on the index page)
logs/ Timestamped run log + JSON session record

Local CollecTRI priors under example_data/collectri_{human,mouse}.csv are used automatically when present (no OmniPath download required).

One-command LRT pipeline

For ordered time / trajectory designs, use run_deseq2_lrt():

out <- run_deseq2_lrt(
  dds = dds,
  var = "genotype",       # or NULL for time-only
  time = "day",
  include_interactions = TRUE,
  run_wgcna = TRUE,
  run_decoupler = TRUE,
  run_viper = TRUE,
  run_ppi = TRUE,
  run_cspa = TRUE,        # top 10 CSPA genes per degPatterns cluster
  save_dir = "results_lrt"
)

LRT mode fits nested full/reduced models, clusters significant genes with degPatterns, runs ORA (not ranked GSEA) per cluster, scores TFs per cluster, and shows per-cluster multihit tables on the index page.

Modular usage (Wald)

Each stage is a standalone function with the same arguments the pipeline uses:

dds_qc <- run_qc(dds, var = "condition", filter_method = "cpm",
                 save_dir = "results/qc")
distance_out <- run_distance_pca(dds_qc, var = "condition",
                                 save_dir = "results/distance")
diffexp_out <- run_diffexp_pipeline(dds_qc, var = "condition",
                                    shrinkage = "ashr",
                                    ranking = "log2FoldChange",
                                    save_dir = "results/deseq2")
gsea_out <- run_gsea_pipeline(
  diffexp_out$results,
  collections = c("HALLMARK", "GOBP", "REACTOME"),
  ranking = "log2FoldChange",
  save_dir = "results/clusterprofiler"
)

# Optional modules …
wgcna_out <- run_wgcna_pipeline(dds_qc, var = "condition", save_dir = "results/wgcna")
decoupler_out <- run_decoupler_pipeline(
  dds_qc, var = "condition", diffexp_out = diffexp_out,
  save_dir = "results/decoupler"
)
viper_out <- run_viper_pipeline(
  dds_qc, var = "condition", diffexp_out = diffexp_out,
  save_dir = "results/viper"
)
ppi_out <- run_ppi_pipeline(
  diffexp_out = diffexp_out, wgcna_out = wgcna_out,
  save_dir = "results/ppi"
)
cspa_out <- run_cspa_marker_pipeline(
  dds_qc, diffexp_out = diffexp_out, save_dir = "results/deseq2/cspa"
)
multihit_out <- run_multihit_pipeline(
  diffexp_out, gsea_out = gsea_out,
  viper_out = viper_out, decoupler_out = decoupler_out,
  cspa_out = cspa_out, save_dir = "results/multihit"
)

render_report(
  dds = dds_qc, var = "condition",
  distance_out = distance_out, diffexp_out = diffexp_out,
  gsea_out = gsea_out, multihit_out = multihit_out,
  wgcna_out = wgcna_out, decoupler_out = decoupler_out,
  viper_out = viper_out, ppi_out = ppi_out, cspa_out = cspa_out,
  save_dir = "results"
)

Two-factor designs

Pass two grouping columns for within-factor contrasts (additive design by default). Set include_interactions = TRUE to use ~ A * B and expand interaction contrasts:

out <- run_deseq2_wald(
  dds,
  var = c("Tissue", "Isotype"),
  include_interactions = TRUE,
  save_dir = "results_2factor"
)

Example runners

In the package source tree:

Rscript --vanilla run_gse189410_wald.R    # single-factor isotype (Wald)
Rscript --vanilla run_gse224465_wald.R    # genotype × celltype (Wald)
Rscript --vanilla run_gse189410_lrt.R     # isotype as time axis (LRT)

Reading the HTML report

Open results/index.html from the results folder (share the whole tree, including lib/ and per-module CSVs). Pages use self_contained = FALSE with relative cross-links and on-disk CSV links. Each report section shows the minimal package call needed to reproduce that module’s results.
